# Security Policy

## Reporting a Vulnerability

If you discover a security weakness in any script or configuration template (such as command injection, unsafe temporary file handling, privilege escalation, or weak mTLS/TLS configuration), please **do not** open a public issue with exploit details.

Report privately via **GitHub Security Advisories** or email `gavicoding@gmail.com` with:

- Affected script or template path
- Reproduction steps and impact assessment

We will review and fix reports promptly.
